# content/music — 音乐 / 吉他笔记

本目录是 Hugo（PaperMod 主题）博客 `content/` 下的音乐板块，用 Obsidian 编辑、Hugo 构建。内容分两类：**吉他课程学习笔记** 和 **弹唱曲谱本**。

## 文件结构

```
music/
├── guitar-by-changyu.md      # 常俞吉他课程 100 节的系统学习笔记（乐理/音阶/技巧）
├── guitar-songbook.md        # 弹唱曲谱本：逐首歌的元信息表 + 原版六线谱贴图
├── <歌名>/                    # 每首歌一个文件夹，存放该曲的原版谱图片
│   └── ...                   # 见「图片约定」
└── CLAUDE.md
```

- **`guitar-by-changyu.md`**：图片用 telegraph-image 外链（`https://telegraph-image-43w.pages.dev/...`），不落本地。
- **`guitar-songbook.md`**：图片一律用**相对路径本地图**（`歌名/文件名`），歌名文件夹与 md 同级。

## 添加一首新歌（核心任务）

1. 在 `music/` 下新建以**歌名（中文原题）命名的文件夹**，把该曲原版谱图片放进去。
2. 图片命名沿用导出原名即可（多为微信导出截图 `微信图片_YYYY-MM-DD_HHMMSS_xxx.png/jpg`）。
3. 在 `guitar-songbook.md` 末尾追加一节，格式见下。

### 曲谱本每首歌的固定格式

```markdown
## 歌名 — 歌手

| 项目   | 内容                          |
| ---- | --------------------------- |
| 词曲   | …                           |
| 编配   | …（谱源，如 大树音乐屋 / 呦呦吉他）        |
| 原调   | `1 = X`                     |
| 选调   | C 调（弹奏用调）                   |
| 变调夹  | Capo = N（无则写「无」）            |
| 拍号   | 4/4                         |
| 主要和弦 | C、G、Am、…                    |

![歌名 第1页](歌名/<page1>.jpg)
![歌名 第2页](歌名/<page2>.jpg)
```

## 图片约定（务必遵守）

- **页序 = 文件名时间戳序**。微信导出图文件名内含 `HHMMSS`，**按该时间戳升序排列即为谱子页码顺序**（已在现有歌曲上核对：第 1 页时间最早、末页最晚）。新增图片若来源不同，需先翻图确认右下角页码（如 `1/7`）再决定顺序。
- 图片引用用**相对路径**，路径含中文不要做 URL 编码（与 `为何我/…jpg` 现有写法保持一致）。
- 谱头通常自带元信息（词曲、原调/选调、拍号、和弦图），录入表格时以图为准。

## 变调夹换算

`Capo` 用于让「选调指法」发出「原调音高」：**原调比选调高 N 个半音 → Capo = N**。
例：为何我 原调 `#F`、选调 C，#F 高 C 六个半音 → Capo = 6。
若原调**低于**选调（如 原调 B♭、选调 C），则无法用变调夹还原，按选调直接弹（音高比原唱略高），变调夹填「无」。
