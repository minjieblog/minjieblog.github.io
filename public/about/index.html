关于我


👋 嗨，我是 Minjie

很高兴你能来到这里！这是我在互联网上的一个小角落，用来记录代码、想法和生活的点滴。

🧑‍💻 关于我

我是一名在读研究生，研究方向包括区块链，web3.0，数据库管理等。当然，目前更加专注于 Java 后端开发。相比起"全栈工程师"这样的标签，我更喜欢把自己定义为一个对计算机技术充满好奇心的探索者。

📖 这个博客写什么

这里主要记录我在技术道路上的成长轨迹，你可能会看到：

技术笔记 - Java 后端开发的实践经验、框架使用心得、踩过的坑和解决方案

项目复盘 - 从需求分析到上线部署，记录项目中的思考和收获

学习记录 - 新技术的探索、算法题的思路、计算机基础知识的整理

随笔杂谈 - 偶尔也会写写读书笔记、游戏感想，或者对技术趋势的一些思考

我希望这里不仅是我个人的知识库,也能给同样在技术路上摸索的你带来一些启发或共鸣。

🎯 技术栈 & 兴趣方向

后端开发：Java、Spring Boot、MyBatis、MySQL、Redis - 这是我的主战场

折腾爱好：除了后端，我还喜欢写点爬虫玩玩，做些自动化小工具来解决日常遇到的重复性工作。总觉得能用代码解决的事情，就不该浪费时间手动操作。有时候为了实现一个自动化脚本，花的时间可能比手动做还多，但那种"一劳永逸"的快感真的很上头。

探索中：对各种能提高效率的技术和工具都充满兴趣，正在不断拓展技术边界…

音乐陪伴：写代码的时候总要听点什么。古典音乐能让思路更清晰，ACG 音乐带来满满的回忆，偶尔也会跟着流行音乐哼哼唱唱。喜欢洗澡的时候k歌······当然，也是个半吊子吉他选手
